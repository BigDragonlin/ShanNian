# 闪念

一个简单的 Mac 软件。输入一条闪念并按回车，它会把时间、当前地点和文字追加到您指定的 Markdown 文档。

## 使用方法

1. 双击打开 `outputs/闪念.app`。
2. 第一次使用时，点“选择文档”选择已有的 `.md` 文件，或点“新建文档”从空白开始。
3. macOS 询问位置权限时点“允许”。
4. 输入文字，按回车保存。

文档中的每条记录类似这样：

```md
- 2026年9月4日 15:20｜上海市 徐汇区｜想到一个新点子
```

## GitHub 自动构建

代码推送到 `main` 分支后，GitHub Actions 会自动完成以下工作：

1. 检查时间、地点和文字能否正确写入 Markdown。
2. 构建只适用于 macOS 的 `闪念.app`。
3. 生成可安装的 `ShanNian-macOS.dmg`。

日常构建完成后，可以在 GitHub 仓库的 **Actions** 页面查看结果。

发布正式版本时，推送 `v1.0.0` 这类版本标签，GitHub 会自动创建 **Release**，并提供可直接下载的 `ShanNian-macOS.dmg`。用户打开 DMG 后，把“闪念”拖到“应用程序”即可完成安装。

当前构建使用本地临时签名，适合自己使用。若要公开分发给其他 Mac 用户，还需要 Apple Developer ID 签名和苹果公证，避免系统显示来源不明提示。
